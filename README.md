## Installation
1. Télécharge NookFlow.zip depuis les Releases
2. Glisse NookFlow.app dans /Applications
3. Premier lancement : clic droit, Ouvrir (ou `xattr -dr com.apple.quarantine /Applications/NookFlow.app`)
4. Autorise les permissions demandées (voir ci-dessous)

## Compiler soi-même
brew install xcodegen
git clone ... && cd NookFlow && ./scripts/install.sh
